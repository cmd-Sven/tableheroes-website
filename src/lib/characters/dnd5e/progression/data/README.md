Structured JSON was assembled via [dnd5eapi.co](https://www.dnd5eapi.co/) (`/api/2014`). Rebuild with:

```bash
node scripts/build-dnd5e-progression-catalog.mjs
```

Curated feat entries beyond the minimal SRD feat set are short rule summaries for the level-up wizard UX; treat non-SRD product identity as out of scope.
